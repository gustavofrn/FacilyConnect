# FacilyConnect

Website institucional para despachantes e consultorias veiculares, desenvolvido para digitalizar o atendimento, apresentar serviços e facilitar a captação de clientes.

## Funcionalidades
- Apresentação de serviços veiculares e etapas de atendimento.
- Formulário que prepara uma mensagem para envio pelo WhatsApp.
- Localização integrada ao Google Maps.
- Navegação responsiva e animações de rolagem.

## Tecnologias
HTML5, CSS3 e JavaScript vanilla.

## Benefícios comerciais
Centraliza informações, facilita o contato com clientes e fortalece a presença digital de prestadores de serviços.

## Execução
Abra `index.html` no navegador, mantendo `style.css` e `script.js` na mesma pasta.

## Pendências
As imagens `fachada.jpg` e `fachada.jpeg` não foram fornecidas. O formulário não possui backend nem realiza consultas veiculares automáticas. Indicadores comerciais devem ser validados pela empresa.
